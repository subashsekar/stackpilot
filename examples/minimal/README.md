# Minimal example

Smallest runnable StackPilot project: one nested Python service.

## Layout

```text
minimal/
  Stackfile.py
  app/
    main.py
```

## Run

```bash
cd examples/minimal
stackpilot run
```

Or:

```bash
python Stackfile.py
```

Press Ctrl+C to stop.

## Graph / doctor

```bash
stackpilot graph
stackpilot doctor
```
